
## **Cheatsheet for time travel**

Git တွင် Commit များကို ပြန်လည်စစ်ဆေးခြင်းနှင့် အချိန်ခရီးသွားသကဲ့သို့ ပြန်ပြင်ခြင်းဆိုင်ရာ အမိန့်များ။

| No. | Command | Description |
| :---: | :--- | :--- |
| 1 | `git log` | commitတွေရဲ့ အသေးစိတ် record ကြည့်ဖို့သုံးတယ်။ |
| 2 | `git log --oneline` | commit တစ်ခုချင်းစီကို တစ်ကြောင်းစီ အတိုချုံး ကြည့်ဖို့။ |
| 3 | `git log --graph --oneline --all` | branchတွေခွဲထားပုံ၊ ဘယ်လိုပေါင်းထားလဲဆိုတာ git graph ပုံစံကို မျဉ်းကြောင်းတွေနဲ့တူတူကြည့်ဖို့။ |
| 4 | `git reset --soft` | သတ်မှတ်ထားတဲ့ commitဆီပြန်သွာတယ် ဒါပေမဲ့ ကိုယ်ရေးထားတဲ့ code changesတွေက staging area မှာ ဆက်ကျန်တယ်။ |
| 5 | `git reset --mixed` (or) `git reset` | commit ရော staging ပါဖျက်ပစ်ပေမဲ့ local fileထဲမှာ codeကဆက်ရှိနေမယ်။ |
| 6 | `git reset --hard` | အရင် commit တုန်းကတိုင်း အပြီးတိုင်ပြန်ပြောင်းပစ်တယ်။ ရေးထားတဲ့ codeအသစ်တွေအကုန်ပျောက်သွားတတ်လို့ သတိထားပြီးသုံးသင့်ပါတယ်။ |
| 7 | `git revert` | တခြားသူတွေနဲ့ အလုပ်တူတူလုပ်တဲ့ခါ အရင် commitတစ်ခုခုမှာ errorတက်လို့ အဲ့ဒီ commitကိုတိုက်ရိုက်ဖျက်မပစ်ပဲ အဲ့ဒီအမှားကို ပြန်ပြင်တဲ့ commitအသစ်တခု ထပ်ဆောက်တယ်။ history က safe ဖြစ်လို့ သုံးရတာ အဆင်ပြေတယ်။ |
